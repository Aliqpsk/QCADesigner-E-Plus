# QCADesigner-E+ engine overlay

This directory contains source files that are intentionally applied on top of the materialized QCADesigner-E engine by `scripts/apply-plus-overlay.sh`.

The upstream source remains under `upstream/` and is never edited by the overlay process.

## Current status

The overlay mechanism is established. Feature files will be added here only after they have a verified integration point in the upstream GTK/application build.
