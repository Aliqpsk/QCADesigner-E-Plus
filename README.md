# QCADesigner-E-Plus

Advanced QCA design, simulation, and energy-analysis environment based on QCADesigner-E.

## Project goals

- Preserve compatibility with QCADesigner/QCADesigner-E `.qca` designs.
- Preserve the reference simulation and energy results before introducing new behavior.
- Add modern analysis, visualization, validation, and optimization capabilities.

## Development policy

The first milestone is a reproducible baseline. Scientific/simulation behavior will not be changed until regression tests exist against the reference implementation.
